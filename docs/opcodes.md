# CETUS VM Opcode Reference

## Базовые стековые операции

Эти инструкции являются фундаментом всей виртуальной машины и используются практически во всех остальных операциях.

```text
OP_CONSTANT
```

Загружает константу из таблицы констант на вершину стека.

```text
OP_POP
```

Удаляет верхнее значение со стека.

```text
OP_OVER
```

Дублирует значение, расположенное под вершиной стека.

---

## Работа с локальными переменными

Локальные переменные хранятся внутри текущего stack frame.

```text
OP_GET_LOCAL
```

Загружает значение локальной переменной на стек.

```text
OP_SET_LOCAL
```

Записывает значение в локальную переменную.

```text
OP_REF_LOCAL
```

Создаёт ссылку на локальную переменную.

---

## Работа с глобальными переменными

Глобальные переменные существуют на уровне всей программы.

```text
OP_DEFINE_GLOBAL
```

Создаёт новую глобальную переменную.

```text
OP_GET_GLOBAL
```

Загружает значение глобальной переменной на стек.

```text
OP_SET_GLOBAL
```

Изменяет значение существующей глобальной переменной.

```text
OP_REF_GLOBAL
```

Создаёт ссылку на глобальную переменную.

---

## Унарные операции

Операции над одним операндом.

```text
OP_NEGATE
```

Арифметическое отрицание.

Пример:

```text
-x
```

```text
OP_NOT
```

Логическое отрицание.

Пример:

```text
!x
```

Бинарные математические операции.

```text
OP_ADD
```

Сложение.

Пример:

```text
a + b
```

```text
OP_SUBTRACT
```

Вычитание.

Пример:


```text
OP_MULTIPLY
```

Умножение.

Пример:


```text

```

Пример:

```text

OP_MODULO
```

## Операции сравнения

Формируют логический результат.

```text
OP_EQUAL
```

Проверка равенства.

Пример:

```text
a == b
```

```text
OP_NOT_EQUAL
```

Проверка неравенства.

Пример:

```text
a != b
```

```text
OP_GREATER
```

Проверка больше.

Пример:

```text
a > b
```

```text
OP_LESS
```

Проверка меньше.

Пример:

```text
a < b
```

```text
OP_GREATER_OR_EQUAL
```

Проверка больше либо равно.

Пример:

```text
a >= b
```

```text
OP_LESS_OR_EQUAL
```

Проверка меньше либо равно.

Пример:

```text
a <= b
```

---

## Управление потоком выполнения

Инструкции переходов и циклов.

```text
OP_JUMP
```

Безусловный переход вперёд.

Используется для:
- if
- else
- пропуска блоков кода

```text
OP_JUMP_IF_FALSE
```

Условный переход.

Переход выполняется, если значение на вершине стека является ложным.

Используется для:
- if
- for
- логических выражений

```text
OP_LOOP
```

Переход назад.

Используется для реализации циклов.

---

## Вызовы функций

Инструкции управления стеком вызовов.

```text
OP_CALL
```

Вызывает функцию.

Операнд содержит количество аргументов.

Используется для:
- пользовательских функций;
- методов;
- встроенных функций.

```text
OP_RETURN
```

Завершает выполнение текущей функции.

Возвращает управление вызывающему коду.

---

# Составные типы данных

Высокоуровневые инструкции для объектов языка.

```text
OP_ARRAY
```

Создаёт массив или слайс из элементов на стеке.

Пример:

```text
[1, 2, 3]
```

```text
OP_STRUCT
```

Создаёт экземпляр структуры.

Пример:

```text
Point{
    x: 10,
    y: 20,
}
```

```text
OP_SLICE
```

Создаёт объект слайса.

Используется при формировании диапазонов элементов.

Пример:

```text
arr[1:5]
```

---

# Индексация и работа со слайсами

Инструкции доступа к элементам коллекций.

```text
OP_GET_INDEX
```

Получает элемент по индексу.

Пример:

```text
arr[i]
```

```text
OP_SET_INDEX
```

Изменяет элемент по индексу.

Пример:

```text
arr[i] = value
```

```text
OP_GET_SLICE
```

Извлекает диапазон элементов.

Примеры:

```text
arr[start:end]
arr[:end]
arr[start:]
```

---

# Работа с полями структур

Инструкции доступа к членам структуры.

```text
OP_GET_MEMBER
```

Получает значение поля структуры.

Пример:

```text
point.x
```

```text
OP_SET_MEMBER
```

Изменяет поле структуры.

Пример:

```text
point.x = 10
```

# Ссылки и указатели

Самый высокий уровень абстракции в текущей VM.

Эти инструкции позволяют реализовать l-value семантику, pointer receiver и модификацию вложенных объектов.

```text
OP_REF_INDEX
```

Создаёт ссылку на элемент массива или слайса.

Пример:

```text
arr[i]
```

как объект присваивания.

Используется при:

```text
arr[i] = value
```

```text
OP_REF_MEMBER
```

Создаёт ссылку на поле структуры.

Пример:

```text
point.x
```

как объект присваивания.

Используется при:

```text
point.x = value
```

```text
OP_POINTER
```

Выполняет запись по ссылке.

Используется для изменения значения, на которое указывает объект ссылки.

Применяется при:
- присваивании через ссылку;
- pointer receiver;
- изменении элементов коллекций;
- изменении полей структур.

---

# Инструкции тестирования

Специальные инструкции TDD-подсистемы CETUS.

```text
OP_ASSERT
```

Проверяет условие теста.

Пример:

```text
assert(x > 0)
```

Если условие ложно:

- выполнение теста прерывается;
- формируется диагностическое сообщение;
- тест считается проваленным.

В новых версиях дополнительно может содержать:
- номер строки исходного файла;
- текст выражения;
- метаданные для отчёта тестирования.
