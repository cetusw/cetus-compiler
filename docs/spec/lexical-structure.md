## Исходный текст

Исходный файл CETUS рассматривается как последовательность символов. Лексический анализатор преобразует её в последовательность токенов.

Лексический анализатор классифицирует входной текст по типам токенов.

## Пробельные символы

Пробельные символы разделяют токены и не попадают в грамматику.

К пробельным символам относятся:

- пробел;
- табуляция;
- перевод строки;
- возврат каретки.

Лексический pipeline сначала строит raw tokens, включая служебные `NEWLINE`, а затем отдельным шагом выполняет automatic semicolon insertion. В parser `NEWLINE` не попадает.

## Комментарии

CETUS поддерживает комментарии:

- однострочный комментарий `//`;
- многострочный комментарий `/* ... */`.

## Идентификаторы

Идентификатор начинается с буквы или `_` и может содержать буквы, цифры и `_`.

Примеры:

```cetus
a
user_id
value123
```

Регистр символов значим.

## Ключевые слова

Лексер распознаёт следующие ключевые слова:

```text
package import func struct var const
if else for range break continue switch case default match return defer
true false nil
```

Слова `int`, `float`, `string`, `bool` зарезервированы для системы типов.

## Литералы

Реализованы:

- `INT_LIT`;
- `FLOAT_LIT`;
- `STRING`;
- `TRUE`;
- `FALSE`.

Целочисленный литерал:

```text
123
```

Вещественный литерал:

```text
10.25
```

Логические литералы:

```text
true
false
```

Строковый литерал является выражением типа `string`.

## Операторы и разделители

Операторы и разделители:

```text
( ) { } [ ] . , ;
:=
= ! != == < <= > >=
+ - * / %
&& ||
```

Зарезервированные операторы:

```text
++ -- & | << >> &^ ?. ?? ...
```

## Automatic semicolon insertion

После raw token scanning lexer преобразует некоторые `NEWLINE` в `SEMICOLON`.

`SEMICOLON` вставляется после перевода строки, если предыдущий значимый токен может завершать statement:

- `IDENTIFIER`;
- `TYPE_IDENTIFIER`;
- `INT_LIT`;
- `FLOAT_LIT`;
- `STRING`;
- `TRUE`;
- `FALSE`;
- `NIL`;
- `)`;
- `]`;
- `}`;
- `break`;
- `continue`;
- `return`;
- `++`;
- `--`.

`SEMICOLON` не вставляется:

- внутри круглых скобок;
- внутри квадратных скобок;
- перед `else`;
- после явно написанного `;`;
- после операторов и разделителей, которые требуют продолжения выражения.

Пример:

```cetus
a := 1
b := 2
```

эквивалентен:

```cetus
a := 1;
b := 2;
```

Исключение:

```cetus
if true {
    println(1)
} else {
    println(2)
}
```

Здесь между `}` и `else` semicolon не вставляется.

## Ошибки лексического анализа

Лексическая ошибка должна содержать строку и описание причины. После первой лексической ошибки дальнейший синтаксический анализ не выполняется.
