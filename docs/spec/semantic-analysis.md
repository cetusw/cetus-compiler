## Назначение

Семантический анализ проверяет программу после построения AST.

## Аннотирование AST

Каждый `ASTNode` может хранить выведенный тип:

```cpp
std::optional<Type>
```

Семантический анализатор записывает типы в существующие AST-узлы через `SetInferredType`.

## Таблица символов

`SymbolTable` хранит соответствие имени и семантического символа. Символ содержит имя и тип.

Идентификатор должен быть определён до использования. Оператор `:=` создаёт символ, если имя отсутствует в таблице символов.

## Области видимости

Блок создаёт новую область видимости. Поиск идентификатора начинается в текущей области и продолжается во внешних областях.

Идентификатор, созданный внутри блока, недоступен после выхода из блока.

Оператор `:=` создаёт новый символ в текущей области, если имя не найдено ни в одной доступной области. Если имя найдено во внешней области, присваивание относится к найденному символу.

## Проверка типов

Проверка выполняется для:

- литералов;
- идентификаторов;
- унарных выражений;
- бинарных выражений;
- присваиваний;
- expression statements;
- списков операторов;
- `if`;
- `printf`.

## Условия

Условие `if` должно иметь truthy-compatible тип: `int` или `bool`.

Если `if` содержит `else`, обе ветки анализируются. `if` имеет тип `void`; типы веток не обязаны совпадать.

Операторы `:=`, expression statement, `printf`, `if`, блок и список операторов имеют тип `void`.

## Диагностики

Семантический анализатор накапливает несколько диагностик. Результат анализа возвращается как `TypeCheckResult`.
