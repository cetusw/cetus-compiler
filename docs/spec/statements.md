## Список операторов

Операторы объединяются в `StatementListASTNode`.

```text
~StmtList~ -> ~StmtList~ ~Stmt~ @statement_list
~StmtList~ -> ~Stmt~ @statement_list_single
```

## Простые операторы

Простой оператор завершается `;`.

```cetus
a := 2;
printf(a);
a + 1;
```

Выражение, записанное как простой оператор, представляется как `ExpressionStatementASTNode` и имеет тип `void`.

## Присваивание

```cetus
a := 10;
```

Если имя `a` отсутствует в таблице символов, создаётся новый символ. Если имя уже определено, тип правой части должен совпадать с известным типом.

Присваивание является оператором и имеет тип `void`.

## Printf

```cetus
printf(1);
printf(a > b);
```

`printf` является встроенной конструкцией вывода.

`printf` имеет тип `void`.

## If

Поддерживаются формы:

```cetus
if a > b {
    printf(1);
}
```

```cetus
if a > b {
    printf(1);
} else {
    printf(0);
}
```

Вложенные `if` разрешены.

`if` является statement-конструкцией и имеет тип `void`. Типы веток `then` и `else` не обязаны совпадать.

## Блок

Блок содержит список операторов:

```cetus
{
    a := 1;
    printf(a);
}
```

Блок имеет тип `void`.

Блок создаёт новую область видимости. Имена, созданные внутри блока, недоступны после выхода из блока.
