## Список операторов

Операторы объединяются в `StatementListASTNode`.

```text
~StmtList~ -> ~StmtList~ ~Stmt~ @statement_list
~StmtList~ -> ~Stmt~ @statement_list_single
```

## Простые операторы

Простой оператор завершается `;`.

```cetus
a := 2;
var b = 3;
printf(a);
a + 1;
```

Выражение, записанное как простой оператор, представляется как `ExpressionStatementASTNode` и имеет тип `void`.

## Объявления переменных

Краткое объявление создаёт новые имена в текущей области видимости:

```cetus
name := "Ivan";
age := 25;
x, y := 10, "string";
```

Если имя уже объявлено в текущей области видимости, краткое объявление является ошибкой. Имя из внешней области может быть скрыто кратким объявлением во внутреннем блоке.

Объявление через `var` поддерживает вывод типа:

```cetus
var city = "Yoshkar-Ola";
var isHappy = true;
```

Объявление через `var` с явным типом:

```cetus
var count int;
var weight float = 70.5;
```

Множественное объявление:

```cetus
var a, b, c int = 1, 2, 3;
```

Количество имён и initializer-выражений должно совпадать, если initializer указан.

## Присваивание

```cetus
a = 10;
a, b = 1, 2;
```

Присваивание изменяет уже объявленные переменные. Если имя отсутствует в доступных областях видимости, это семантическая ошибка.

Тип правой части должен совпадать с типом соответствующей переменной.

Присваивание является оператором и имеет тип `void`.

## Return

`return` завершает выполнение текущей функции.

```cetus
return;
return a + b;
```

`return` вне функции является семантической ошибкой.

```cetus
printf(1);

```

`printf` является встроенной конструкцией вывода.

`printf` имеет тип `void`.

## If

Поддерживаются формы:

```cetus
if a > b {
    printf(1);
}
```

```cetus
if a > b {
    printf(1);
} else {
    printf(0);
}
```

Вложенные `if` разрешены.

`if` является statement-конструкцией и имеет тип `void`. Типы веток `then` и `else` не обязаны совпадать.

## Блок

Блок содержит список операторов:

```cetus
{
    a := 1;
    printf(a);
}
```

Пустой блок разрешён:

```cetus
{
}
```

Блок имеет тип `void`.

Блок создаёт новую область видимости. Имена, созданные внутри блока, недоступны после выхода из блока.
