## Вывод

В языке определена встроенная функция вывода. Она регистрируется как `BUILTIN_FUNCTION`, а не как пользовательская функция.

```cetus
printf(1);
```

`printf` принимает один truthy-compatible аргумент: `int`, `float` или `bool`. Функция возвращает `void`.
